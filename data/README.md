# Data

Coloca aqui los archivos de datos espaciales para el proyecto:

- **Datos de puntos**: CSV o shapefiles con coordenadas y variable de respuesta
- **Covariables raster**: Archivos `.tif` (clima, elevacion, infraestructura, etc.)
- **Limites administrativos**: Shapefiles o GeoPackage (`.gpkg`)
- **Rasters de poblacion**: Para agregacion ponderada (opcional)

Los archivos grandes (`.tif`, `.shp`, etc.) estan excluidos del control de versiones via `.gitignore`.
